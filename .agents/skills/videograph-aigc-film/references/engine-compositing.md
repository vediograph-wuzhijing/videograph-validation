# 在 VideoGraph 引擎里合成 AIGC 素材

## 一个场景模块服务全片

所有镜头提交同一份场景源码，按 `ctx.params.kind` 切换版式（`black / video / phone / map / wishes / end` …）；每镜 params 带 `shot`（镜头 id，素材路径用它，不依赖引擎内部 id 格式）、`kind`、`ov`（叠层参数）、`frames`（帧数）、`subs`（本镜字幕）。

## AI 视频 = 帧序列

引擎没有异步逐帧钩子，`render()` 必须同步。做法：

1. ffmpeg 截本镜时长（+0.3 s 余量）转帧：`ffmpeg -i clip.mp4 -t <dur+0.3> -vf scale=1280:720 -q:v 3 <public>/<proj>/<shot>/%04d.jpg`，放进工程 `engine/app/public/`（引擎静态目录，`init()` 用相对路径 fetch）。
2. `init()`：`createImageBitmap(await (await fetch(url)).blob())` 预解码全部帧。
3. `render()`：`i = clamp(floor(f.lt * 24), 0, n-1)`，`drawImage` 到 Layer2D 再叠字。导出按镜头分段渲染，每段只加载本镜的帧，内存可控（6 秒 ≈ 150 帧 ≈ 0.5 GB）。
4. 缺视频时用关键帧做缓推 + 轻微横移 + 光尘兜底，整片先跑通，视频到了再替换（只重渲这些镜头）。

## 叠层

- **字幕**：底部居中，旁白暖白、角色纯白，黑色柔影；显示时长 ≈ 0.7 s + 每字 0.2 s。
- **贴在物件上的字**（愿签名字等）：物件在视频里移动时不要硬贴，改为“从物件上浮现的发光字”；亮底上的字用深色墨迹 + 金色外发光，保证对比度。
- **手机界面**：关键帧要求手机正对镜头；用像素检测求屏幕矩形（`L<22` 的行/列占比 > 60%），界面在 `clip(roundRect(屏幕))` 内绘制，镜头推近时对底图与界面用同一个变换。加：状态栏、键盘与逐键亮起、屏幕光溢出到手（加色径向渐变）、打字微震、玻璃反光、发送眩光。纯矢量手机会显假，用户会指出。
- **通知横幅**：卡片带 app 图标、来源、时间；落地时 outBack + 横向震动；避开人脸（检查静帧决定左右位置）。
- **地图/图鉴拼合**：把图切成 6×4 碎片，从随机偏移与旋转飞回原位；标题区加暗色托底。
- **系统提示/金字标语**：金色渐变 + 发光；放在不遮脸的位置——视频里人物会比关键帧更近更偏，**用视频帧的静帧确认位置**。

## 节奏

- 音轨是自制的：已知 BPM 的段落用 `song_analysis_patch` 写真实网格（分析器常把 120 判成 240、96 判成 177）。
- 节奏先用镜头内的东西表达：人物动作（走路用逐帧行走循环，不要把一张立绘平移）、运镜、换景、叠层的出入。整帧冲击（`post.zoom` 推镜、`flash` 闪白、`shake` 震动）只留给全片少数几个重音（段落爆点、落版），**不要逐拍常开**：长时间随拍一闪一震，观感疲劳，用户会指出。
- 节奏报告的“死区”是提示不是任务。先判断是否有意的停留；要补就补镜头内的运动，不要为了消掉提示去加全屏闪白、震动或逐拍推镜。
- 自由节奏的开场按配音与情节切，不为指标挪切点；在交付说明里解释节奏报告的“切在拍外”。

## 特效箱

- 安静段落要在某一帧“砸”出冲击（弹窗、按钮、落版）：`timed-impact`，`atTime` = 歌曲秒，`centerX/centerY` = 冲击点（Y 从底部算），与音轨里的音效同一刻。
- 氛围：`bloom-glow`（柔光辉光）、`light-leak`（漏光）。在无鼓点段把它们的节拍绑定设为 `null`，避免乱闪。
- 改意见时先 `effects` 后 `source`（提交后再改镜头会让意见响应退回 pending）。
