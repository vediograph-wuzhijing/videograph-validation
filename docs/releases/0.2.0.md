# VideoGraph 0.2.0

Windows本地完整工作台，包含审阅室、HTTP、65项MCP工具、独立视频引擎、分析适配、源码、Node运行时与离线npm依赖。

## 本版优先解决的五件事

1. **数据库与连接稳定性**：大任务输入/结果外置，任务列表摘要分页，修订按内容哈希共享大数据；重操作移出HTTP主线程，前端先轮询轻量版本。增加可恢复迁移、引用保护保留策略、服务过期与积压诊断。实际工程隔离副本测试的总存储减少93.5%，并发健康检查P95约7.05毫秒；该测量不代表所有硬件或工程。
2. **连续画面自查**：filmstrip通过MCP返回带时间/拍点/歌词的拼图；导演要求每镜及非硬切转场提供当前版本动态证据。新制作流程默认每轮读连续帧，提供约2秒12帧的调用方式，导出前列明无法验证的播放和聆听项目。
3. **草稿与共享源码**：未提交代码可做类型/初始化着色器检查、少量静帧或播放器预览，不建任务或修订。正式共享模块一次提交完整绑定，避免相同源码逐镜重复提交；版本、锁、人工意见和导演租约原子校验。
4. **引擎标准件**：相机/世界卡片/投影、sky/ocean/underwater程序化环境、逐字素文字动画、图层分离和选择性后期，均可通过组件工具检索。新歌工程使用包内许可引擎与字体，环境是可组合基础，不是物理仿真。
5. **审阅意见直达AI**：收件箱可按工程/镜头读取目标、锚点与保留项；每轮直接读意见、逐条回应，再交给人比较采用。AI不能接受意见、接受自评或解锁目标。

## 制作方法

shotcraft升级为1.6.0，新增[PV制作流程](../../skills/shotcraft/references/pv-production.md)，通过`craft_guide(topic=pv-production)`和MCP resource读取。开工先检索现有特效/转场/组件；参考作品先看抽帧与运动，再读代码；只提交改变的镜头，先少量草稿，再局部验证。包含2D/3D混合经验、按歌词语义选择文字配方、环境参数与许可、外部MIDI/歌词对拍核对方法。

已有真值可在建工程时直接输入节拍/段落/歌词，跳过自动模型分析；时间来源与估算质量保留。切点可明确选择长音持续段或警告策略，无需人为缩短歌词。

## OpenUtau冻结

歌声模块保留本版现有CLI/HTTP/MCP/界面能力，**仅修复已确认的bug**，不再主动优化、扩展或更换后端。按用户实际测试，现有模型尚不能很好调用此工具，作为未来探索方向保留。技术渲染、音高和频段报告通过不等于模型能可靠完成歌声制作，也不等于听感已由人接受。

## 安装与许可

下载Windows x64 ZIP，解压到可写目录；运行`Doctor.cmd`检查外部依赖，按[运行手册](../OPERATIONS.md)配置，使用`Start-Workbench.cmd`启动，`MCP.cmd`接入AI客户端。停止工具仅处理核验归属且空闲的实例，忙碌时拒绝停止；不会自动重启日常制作服务。

FFmpeg/ffprobe、Edge/Chromium由使用者提供；需要自动分析时另配Python/模型，需要实验歌声合成时另配合法声库/重采样器。**音源、声库、歌曲/MIDI/视频、用户工程、模型权重和凭据不随源码树或软件包分发。** 软件GPL-3.0-only；引擎、字体、Node与依赖保留各自许可证和通知。
